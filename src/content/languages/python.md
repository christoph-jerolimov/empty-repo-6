## About

Python emphasises readability, using indentation rather than braces to delimit blocks and a small set of clear constructs summarised in "The Zen of Python". It ships with a large standard library, supports objects, closures, generators, comprehensions and async programming, and is dynamically typed with optional type hints that external checkers can enforce. An enormous ecosystem, including NumPy, pandas, Django, Flask, PyTorch and TensorFlow, has made Python the lingua franca of machine learning and data analysis while it remains a favourite for automation, web backends and education.

## History

Guido van Rossum started Python over the 1989 Christmas holidays at CWI in Amsterdam as a successor to the ABC teaching language, naming it after *Monty Python's Flying Circus*; the first release followed in February 1991. Python 2.0 (2000) introduced list comprehensions and garbage collection of cycles, and Python 3.0 (2008) made backwards-incompatible fixes such as Unicode strings by default, which took the community more than a decade to fully adopt. Van Rossum served as "Benevolent Dictator For Life" until 2018, when governance passed to an elected steering council. Recent releases have focused on performance, a free-threaded build without the global interpreter lock, and a yearly release cadence.
