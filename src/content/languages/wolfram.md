## About

In the Wolfram Language every piece of data, code, image or formula is a symbolic expression of the form `head[arg1, arg2, ...]`, and computation proceeds by pattern-based term rewriting. It ships with thousands of built-in functions covering algebra, calculus, statistics, machine learning, graphs, geography and image processing, plus curated knowledge about the real world that can be queried directly. The notebook interface mixes code, typeset mathematics, plots and interactive controls in one document, a model that Jupyter later brought to other languages.

## History

Stephen Wolfram released Mathematica 1.0 in June 1988, building on his earlier SMP system, and it quickly became the standard tool for symbolic computation in physics, mathematics and engineering. The programming language inside it was formally named the Wolfram Language in 2013, by which time it also powered the Wolfram|Alpha answer engine launched in 2009. The company has since released a free Wolfram Engine for developers, cloud deployment and integration with the Raspberry Pi, while continuing annual Mathematica releases.
